# Ricerca Testuale Accesso Digitale per NVDA

**Autore:** Maurizio Barra  
**Versione:** 1.0.0  
**Compatibilità NVDA:** 2023.1 o superiore  

## Descrizione
Ricerca Testuale Accesso Digitale è un add-on per lo screen reader NVDA progettato per velocizzare ed estendere la ricerca di frasi e parole chiave all'interno di file di testo, documenti Word/PDF, immagini e collezioni multimediali.

## Caratteristiche Principali
* **Scorciatoia Globale:** `NVDA + Shift + Control + F` seguita da `F` per aprire la maschera di ricerca.
* **Memoria Automatica:** Ricorda l'ultimo percorso utilizzato e lo mantiene anche dopo i riavvii o gli aggiornamenti.
* **Menu Contestuale Avanzato (`Shift + F10` o Tasto APPLICAZIONI):** Permette di copiare il blocco notizia con il contesto della parola chiave, copiare l'intero contenuto (o l'immagine da incollare direttamente), aprire la cartella contenitore o inviare il file ad un'altra destinazione.
* **Ordinamento Dinamico:** Risultati ordinati di default dal più recente al meno recente, con possibilità di riordinamento alfabetico o per data.
* **Cattura Schermo Istantanea:** `Alt + K` all'interno della finestra per salvare uno screenshot nella cartella dedicata.
* **Guida Integrata:** `NVDA + Shift + Control + F` seguita da `H` per aprire la guida completa direttamente nel browser predefinito.
