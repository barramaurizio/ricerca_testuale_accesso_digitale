Novità nella Versione 1.6.1
(Pubblicata)

- Arrivi dell’ultimo minuto: file aggiunti alla cartella durante la ricerca vengono esaminati a fine coda

Novità nella Versione 1.6.0
(Pubblicata)
- Motore OCR cloud: Google Cloud Vision con chiave API personale dell’utente (gemello Standalone + Add-on)
- Ogni utente inserisce la propria chiave (Strumenti → Chiave API Google Vision, oppure pulsante «Chiave Google»)
- Nessuna chiave condivisa nel software: la tua vale solo per te; gli altri usano la loro
- Più efficace su scritte stilizzate / grafiche rispetto a Windows e EasyOCR
- Match OCR tollerante: spazi, lettere mancanti (es. SQUAD ST ≈ squadlist), ritentativi Vision su fascia titolo
- Copia Testo pulito: può ripristinare la parola cercata se l’OCR l’ha mutilata; OCR completo resta fedele al motore
- Correzione lista risultati: a fine ricerca (anche con 0 hit) non resta più «Ricerca in corso… attendere prego.»
- ZIP opt-in: previsto dopo questa release

Novità nella Versione 1.5.8
(Pronta al rilascio — ultima pubblicata: 1.5.7)
- OCR opt-in: casella «Includi testo in immagini e PDF scansionati» (spento di default)
- Motori: Windows.Media.Ocr (predefinito) oppure EasyOCR opzionale (scritte stilizzate)
- Menu / elenco «Motore OCR»; preferenze e profili: include_ocr, ocr_engine
- Immagini JPG/PNG/TIFF/WebP/BMP/GIF… → [IMG-OCR]; PDF scansionati → [PDF-OCR]
- Preprocess (contrasto, stripe, ritagli, rotazioni) + match fuzzy / confusabili / alias BIRTHDAY
- Sinonimi OCR: cercando «birthday» trova anche «compleanno» (e viceversa) nel testo immagine
- Ritaglio destro «clean» + rotazioni per BIRTHDAY verticale; se EasyOCR non matcha, completa con Windows
- Copia Testo OCR: «Copia Testo pulito» (HAPPY/BIRTHDAY+nome) e «Copia OCR completo» (tutto, canzone inclusa)
- OCR completo senza parola chiave: attiva OCR, lascia vuoto il testo, Avvia → elenco immagini con Copia/Salva
- Scelta della migliore variante OCR (meno «zuppe» di caratteri su documenti)
- Anti falsi positivi (es. tribunale); Copia Testo dal risultato OCR (testo riconosciuto)
- Cache OCR per motore; contatori nello stato; gemello Standalone + Add-on
- EasyOCR Standalone: pip install -r requirements-ocr-easy.txt (modelli al primo uso)
- Futuro (non in 1.5.8): Azure/Google con chiave personale dell’utente
- Restano voce 1.5.7, posta 1.5.6, date, profili e filtri
