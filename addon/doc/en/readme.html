Ricerca Testuale Accesso Digitale v1.8.8

Author: Maurizio Barra (Accesso Digitale)

An NVDA add-on for accessible text search across files, folders and entire drives, with jump-to-line, native EML reading, RSS/Atom feeds and Thunderbird Feeds.

What's New in Version 1.8.8

Supported formats

  • Text: .txt, .log, .csv and similar
  • Documents: Word (.docx, .doc), PDF (text and, when scanned, page image), EPUB (.epub)
  • Mail: .eml files (native reading) and Thunderbird-style mailbox / Feeds containers
  • Feeds: RSS/Atom URLs, local feed files, OPML, Mail\Feeds folders
  • Images and scanned PDFs: with the OCR checkbox (opt-in) text becomes searchable; OCR engine picker; menu offers clean/full OCR copy and Copy/Save Image

How to use RSS and Thunderbird Feeds

  1. Open search with NVDA + Shift + Control + F.
  2. In the path field you can:
    • paste one or more http(s) URLs;
    • point to .rss/.atom/.xml/.opml files;
    • or press Feed Thunderbird to insert profile Feeds folders automatically.
  3. Type the keywords and start the search (Enter in the text field or the Search button).
  4. In the results list:
    • [RSS] / [FEED]: Enter opens the article in the browser;
    • [FEED-RIGA] (if raw occurrences are enabled): Enter jumps to the line in the file (Notepad++ when available).
About counts: one article may contain the keyword several times. Distinct articles are the [FEED] results; raw occurrences in the file are [FEED-RIGA]. Status explains both numbers.

How to reach the exact point in Word documents

  1. From the results list, press the Applications key on the desired Word file.
  2. Select «Copy News Block / Phrase with keyword».
  3. Open the Word document from the results.
  4. Press Control + Shift + T to start targeted search.
  5. Paste with Control + V and press Enter.
  6. Select the match with the arrow keys and confirm with Enter.
  7. When speech announces the next result, press Escape: the cursor lands on the searched text (then NVDA + Down Arrow for continuous reading).

If you prefer automatic opening without these steps, also use the Standalone (.exe) version.

Global NVDA shortcuts

  • NVDA + Shift + Control + F: open the main search window.
  • NVDA + Shift + Control + S: open the commands and info dialog.
  • NVDA + Shift + Control + D: open the PayPal donation page.

Shortcuts in the search window

  • Ctrl + H: recall recent search queries.
  • Ctrl + Shift + H: recall recent search paths.
  • Alt + T: scan the whole PC (all active drives).
  • Alt + N: cancel the current search and keep results already found.
  • Alt + I: version and author info.
  • Alt + P: announce status; press twice quickly to copy status to the clipboard.
  • Copy Status button: copy search details to the clipboard.
  • Ctrl + F: jump to the «Filter results» box.
  • TAB / Alt+S / S: also reach the «Progress status» field readable by the screen reader.
  • Alt + K: screenshot into «Screen captures».
  • Ctrl + P: quick print of listed results.
  • Ctrl + E: export results.
  • Ctrl + D: add the current path to bookmarks.
  • Ctrl + Shift + P: save the current search profile.
  • Ctrl + Shift + L: load a search profile.
  • Ctrl + U: check for updates (prefers the .nvda-addon asset from the release).
  • Enter (in the text field): start the search immediately.
  • Enter (on results): open the file at the line, or open the feed article in the browser.
  • Space / F4: immediate spoken preview of the context.
  • F7: toggle RTAD announcements (Mute).
  • Voice menu: Mute RTAD; rate/voice = NVDA settings.
  • OCR: checkbox under feeds (opt-in; slower) + Motore OCR list (Windows default; EasyOCR if available).
  • Applications key: context menu (Copy clean text, Copy full OCR, Copy/Save Image...).
  • F1: command guide (from the Help menu).
  • Escape: close the window.

Help menu

  • What's New: summary of the current update.
