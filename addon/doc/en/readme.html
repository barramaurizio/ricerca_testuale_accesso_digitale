Introduction

An NVDA add-on designed to perform fast and advanced text searches across text files, Word documents, PDFs, images (via basic OCR), and emails on your computer.

How to reach the exact point in Word documents

  1. From the add-on results list, press the Applications key on the desired Word file.
  2. Select "Copy News Block / Phrase with keyword" to copy the exact phrase to the clipboard.
  3. Open the Word document directly from the results.
  4. Press the shortcut key combination Control + Shift + T to trigger targeted document search.
  5. Paste the copied text by pressing Control + V and press Enter.
  6. Listen to NVDA's speech feedback announcing the results. Use arrow keys to select the match and press Enter.
  7. When the synthesizer announces "One result, next result Button", press the Escape key: the Word cursor will position itself precisely over the searched text, ready for reading (you can use NVDA + Down Arrow to start continuous reading).

Main Keyboard Shortcuts

  • NVDA + Shift + Control + F: Open the main search window.
  • NVDA + Shift + Control + S: Open the shortcuts dialog.
  • NVDA + Shift + Control + D: Open the PayPal donation page.
