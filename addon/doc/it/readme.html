Ricerca Testuale Accesso Digitale v1.5.4

Autore: Maurizio Barra (Accesso Digitale)

Componente aggiuntivo per NVDA: ricerca testuale accessibile su file, cartelle e intere unità, con salto alla riga, lettura EML nativa, feed RSS/Atom e Feed Thunderbird.

Novità Versione 1.5.4
  • Profili di ricerca: salva percorso, tipo file, estensione, opzione feed e (opzionale) testo; menu Profili; Ctrl+Shift+P / Ctrl+Shift+L.
  • Gestisci profili: rinomina o elimina; avvio automatico opzionale se il profilo include il testo.
  • Filtri tipologici più ricchi: più estensioni in Immagini (gif, webp, tif…), Audio/Video (m4a, flac, mov…) e Documenti (html, md, rtf, odt…).
  • Scorciatoie Alt senza conflitti: ciascuna lettera una sola azione (T/P/N/I/S/K); Avvia ricerca con INVIO nel campo testo.
Novità Versione 1.5.3
  • PDF migliorato: testo reale dagli stream compressi, anche ToUnicode/CID (tabellini Leghe); niente più spazzatura tipo endstream/simboli.
  • Menu contestuale: «Copia Testo», «Copia Immagine» e «Salva Immagine...» separate (non più un solo comando misto).
  • PDF scansionati (es. ricevute ScanSnap): Copia Testo avvisa che non c’è testo; Copia/Salva Immagine esportano la pagina grafica (non i soli loghi).
  • Data documento (gg/mm/aaaa) nei risultati PDF; etichette «Testo PDF» / «Nome File».
Novità Versione 1.5.2
  • Lettore email/MBOX più sicuro: caricamento in secondo piano; allegati PDF/binari esclusi dal testo (nota a fine messaggio).
  • Data messaggio (gg/mm/aaaa) anche nei risultati MBOX; apertura MBOX nel lettore interno.
Novità Versione 1.5.1
  • Cronologia ricerche: salva in locale gli ultimi testi e percorsi. Pulsante Cronologia o Ctrl+H per riprendere un testo; Ctrl+Shift+H per un percorso; menu Cronologia con elenco rapido e svuota.
Novità Versione 1.5.0
  • Feed RSS/Atom: cerca in URL http(s), file .rss/.atom/.xml e elenchi OPML. Più percorsi o URL separati da ; o ,.
  • Feed Thunderbird: pulsante dedicato che individua le cartelle Mail\Feeds dei profili. Ricerca a testo pulito (oggetto/corpo), un risultato per articolo, Invio apre il link originale nel browser.
  • Occorrenze grezze opzionali: casella per elencare anche le righe [FEED-RIGA] oltre agli articoli [FEED] (utile per confrontare i conteggi con Notepad++).
  • Indici Thunderbird esclusi: file .msf e indici simili non vengono scansionati.
  • Ordinamento e stato: risultati feed ordinati per data articolo; nello stato si indica la differenza tra articoli e occorrenze grezze.
  • Lettura con Thunderbird aperto: i feed locali si possono leggere anche se Thunderbird è in esecuzione.
  • Filtro risultati: Ctrl+F salta alla casella di filtro della lista.

Formati supportati

  • Testo: .txt, .log, .csv e simili
  • Documenti: Word (.docx, .doc), PDF (testo e, se scansionati, pagina immagine)
  • Posta: file .eml (lettura nativa) e contenitori stile mailbox / Feed Thunderbird
  • Feed: URL RSS/Atom, file feed locali, OPML, cartelle Mail\Feeds
  • Immagini: OCR di base su .jpg, .png, .bmp; dal menu si possono anche copiare o salvare

Come usare i Feed RSS e Thunderbird

  1. Apri la ricerca con NVDA + Shift + Control + F.
  2. Nel campo percorso puoi:
    • incollare uno o più URL http(s);
    • indicare file .rss/.atom/.xml/.opml;
    • oppure premere Feed Thunderbird per inserire automaticamente le cartelle Feeds dei profili.
  3. Digita le parole da cercare e avvia la ricerca (Invio sul campo testo o pulsante Cerca).
  4. Nella lista:
    • [RSS] / [FEED]: Invio apre l’articolo nel browser;
    • [FEED-RIGA] (se hai attivato le occorrenze grezze): Invio salta alla riga nel file (Notepad++ se disponibile).
Nota sui conteggi: un articolo può contenere la parola più volte. Gli articoli distinti sono i risultati [FEED]; le occorrenze grezze nel file sono le [FEED-RIGA]. Lo stato di avanzamento spiega entrambi i numeri.

Come raggiungere il punto esatto nei documenti Word

  1. Dalla lista dei risultati, premi il Tasto Applicazioni sul file Word desiderato.
  2. Seleziona «Copia Blocco Notizia / Frase con parola chiave».
  3. Apri il documento Word dai risultati.
  4. Premi Control + Shift + T per avviare la ricerca mirata.
  5. Incolla con Control + V e premi Invio.
  6. Seleziona la corrispondenza con le frecce e conferma con Invio.
  7. Quando la sintesi annuncia il risultato successivo, premi Esc: il cursore si posiziona sul testo cercato (poi NVDA + Freccia Giù per la lettura continua).

Se preferisci l’apertura automatica senza questi passaggi, usa anche la versione Standalone (.exe).

Scorciatoie globali NVDA

  • NVDA + Shift + Control + F: apre la finestra di ricerca principale.
  • NVDA + Shift + Control + S: apre la finestra comandi e informazioni.
  • NVDA + Shift + Control + D: apre la pagina donazioni PayPal.

Scorciatoie nella finestra di ricerca

  • Ctrl + H: cronologia testi cercati.
  • Ctrl + Shift + H: cronologia percorsi usati.
  • Alt + T: scansione su tutto il PC (tutte le unità attive).
  • Alt + N: annulla la ricerca in corso e mantiene i risultati già trovati.
  • Alt + I: info versione e autore.
  • Alt + P: annuncia lo stato; due volte in rapida successione copia lo stato negli appunti.
  • Pulsante Copia Stato: copia i dettagli della ricerca negli appunti.
  • Ctrl + F: salta alla casella «Filtra i risultati».
  • TAB / Alt+S / S: raggiunge anche il campo «Stato avanzamento» leggibile dallo screen reader.
  • Alt + K: screenshot in «Catture di schermata».
  • Ctrl + P: stampa rapida dei risultati in lista.
  • Ctrl + E: esporta risultati.
  • Ctrl + D: aggiunge il percorso attuale ai segnalibri.
  • Ctrl + Shift + P: salva il profilo di ricerca attuale.
  • Ctrl + Shift + L: carica un profilo di ricerca.
  • Ctrl + U: verifica aggiornamenti (preferisce il file .nvda-addon dalla release).
  • Invio (sul campo testo): avvia subito la ricerca.
  • Invio (sui risultati): apre il file alla riga, oppure l’articolo feed nel browser.
  • Spazio / F4: anteprima vocale immediata del contesto.
  • Tasto Applicazioni: menu contestuale del risultato (tra cui Copia Testo, Copia Immagine, Salva Immagine...).
  • F1: guida ai comandi (da menu Aiuto).
  • Esc: chiude la finestra.
