```markdown
## 🇮🇹 Italiano

- **Profili di ricerca:** salva percorso, tipo file, estensione personalizzata, opzione feed e (opzionale) testo.
- Menu **Profili**: Salva attuale, Carica, Gestisci (rinomina / elimina); elenco rapido.
- Scorciatoie: **Ctrl+Shift+P** (salva), **Ctrl+Shift+L** (carica); Alt senza conflitti (T/P/N/I/S/K).
- Se includi il testo, puoi attivare l’**avvio automatico** della ricerca all’apertura del profilo.
- Filtri tipologici più completi: immagini (gif/webp/tif…), audio/video (m4a/flac/mov…), documenti (html/md/rtf/odt…).

## 🇬🇧 English

- **Search profiles:** save path, file type, custom extension, feed option and (optional) query text.
- **Profiles** menu: Save current, Load, Manage (rename / delete); quick list.
- Shortcuts: **Ctrl+Shift+P** (save), **Ctrl+Shift+L** (load); conflict-free Alt (T/P/N/I/S/K).
- Optional **auto-start** search when the profile includes a query.
- Richer type filters: images (gif/webp/tif…), audio/video (m4a/flac/mov…), documents (html/md/rtf/odt…).
```
