════════════════════════════════════════════════════════
COMUNE (Add-on + Standalone)
════════════════════════════════════════════════════════

- OCR Google Cloud Vision (opt-in): riconoscimento testo cloud sulle immagini
  difficili; richiede Internet e la chiave API PERSONALE di ciascun utente.
- Dove inserire la chiave: menu Strumenti → «Chiave API Google Vision…»
  oppure pulsante «Chiave Google» accanto a Motore OCR.
- Nessuna chiave condivisa nel software: la chiave di Maurizio vale solo
  per Maurizio; ogni altro utente crea e inserisce la propria.
- Motore OCR: terza voce «Google Cloud Vision (chiave API personale)».
- Correzione lista risultati: a fine ricerca (anche con 0 hit) non resta
  più «Ricerca in corso… attendere prego.» — compare «Nessun risultato trovato.»
- Restano guida pratica + EPUB 1.5.9, OCR locale Windows/EasyOCR 1.5.8,
  Mute/voce 1.5.7, posta 1.5.6, profili e filtri.
- ZIP opt-in: previsto dopo questa release.

Come ottenere la chiave (per te e per la guida utenti):
  1) Account Google → Google Cloud Console
  2) Crea un progetto (o usane uno esistente)
  3) Abilita «Cloud Vision API»
  4) Credenziali → Crea credenziali → Chiave API
  5) Incolla la chiave in RTAD (Strumenti / Chiave Google)
  Nota: possono applicarsi quote e costi Google; RTAD non fattura nulla.
