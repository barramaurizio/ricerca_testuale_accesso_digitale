════════════════════════════════════════════════════════
COMUNE (Add-on + Standalone)
════════════════════════════════════════════════════════

- Arrivi dell’ultimo minuto: se durante la ricerca aggiungi file nella
  cartella cercata, a fine coda RTAD li riprende e li esamina.
- ZIP opt-in: casella «Includi contenuti negli archivi ZIP» — cerca testo
  nei membri testuali (.txt, .md, .html, .xml, .json, .log, .py, …)
  senza scompattare su disco; risultati con prefisso [ZIP].
- Durante la ricerca la lista non torna più vuota («sconosciuto» con NVDA):
  resta «Ricerca in corso… attendere prego.» fino alla fine.
- Voce SAPI (Standalone): se l’Id salvato non è più valido
  (HRESULT -2147200967) ripristina automaticamente la voce predefinita;
  in Ctrl+Shift+V compare anche «Voce predefinita di Windows».
- Restano OCR Google Vision 1.6.0, guida pratica + EPUB 1.5.9,
  OCR locale Windows/EasyOCR 1.5.8, Mute/voce 1.5.7, posta 1.5.6,
  profili e filtri.

Tag:
v1.6.1

Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.6.1

Descrizione:

```markdown
## 🇮🇹 Italiano

- **Arrivi dell’ultimo minuto**: file aggiunti alla cartella mentre la ricerca è in corso vengono esaminati a fine coda.
- **ZIP opt-in**: casella «Includi contenuti negli archivi ZIP» — cerca testo nei file dentro `.zip` (txt, md, html, csv, json, log, …); risultati `[ZIP]`.
- **Lista durante la ricerca**: non torna più vuota («sconosciuto» con NVDA); resta «Ricerca in corso… attendere prego.» fino alla fine.
- Restano OCR Google Cloud Vision 1.6.0, guida pratica + EPUB 1.5.9, OCR locale 1.5.8, Mute 1.5.7 e posta 1.5.6.

## 🇬🇧 English

- **Last-minute arrivals**: files added to the search folder while a search is running are picked up at the end of the queue.
- **ZIP opt-in**: checkbox to search text inside `.zip` members (txt, md, html, csv, json, log, …); results use the `[ZIP]` prefix.
- **Results list while searching**: no longer goes empty (NVDA “unknown”); it keeps “Search in progress… please wait.” until the end.
- Google Cloud Vision OCR 1.6.0, practical guide + EPUB 1.5.9, local OCR 1.5.8, Mute 1.5.7 and complete mail 1.5.6 remain.
```

Asset(s):
