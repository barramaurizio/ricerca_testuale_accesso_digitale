COMUNE (Add-on + Standalone)
════════════════════════════════════════════════════════

- Notifica di sistema a fine ricerca: toast WinRT nel Centro notifiche
  Windows (Windows+N), resta finché non la apri/OK
  (Strumenti → «Notifica a fine ricerca…», attiva di default;
  i bip e l’annuncio vocale restano).
- Svuota cache OCR: voce in Strumenti per cancellare i file in
  ocr_cache (dopo un update o se un’immagine non viene riletta bene).
- Se un’immagine matcha solo sul nome file ma l’OCR ha prodotto testo,
  il risultato resta utilizzabile: prefisso [IMG-OCR], «Nome File + OCR»,
  e Copia OCR/Testo pulito funzionano (prima il testo OCR non veniva allegato).
- Restano ZIP / arrivi ultimo minuto / lista stabile 1.6.1,
  OCR Google Vision 1.6.0, guida pratica + EPUB 1.5.9,
  OCR locale 1.5.8, Mute/voce 1.5.7, posta 1.5.6, profili e filtri.

Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.6.2

Descrizione:

```markdown
## 🇮🇹 Italiano

- **Notifica a fine ricerca**: resta nel **Centro notifiche** Windows (Windows+N) finché non la apri; Strumenti, attiva di default; restano bip e annuncio NVDA.
- **Svuota cache OCR** dal menu Strumenti (utile dopo un aggiornamento o se un’immagine non viene riletta correttamente).
- **Google Vision**: ritentativi anche su fasce basse e margini (byline/firma) e unione dei pezzi OCR utili; cache OCR aggiornata (v17).
- **Immagini OCR**: se il match è solo sul nome file ma l’OCR ha letto testo, il risultato è `[IMG-OCR]` «Nome File + OCR» e Copia OCR funziona.
- Restano ZIP e arrivi dell’ultimo minuto 1.6.1, OCR Vision 1.6.0, guida/EPUB 1.5.9, OCR locale 1.5.8, Mute 1.5.7 e posta 1.5.6.

## 🇬🇧 English

- **End-of-search notification**: stays in the Windows **Action Center** (Windows+N) until you open it; Tools menu, on by default; beeps and NVDA speech remain.
- **Clear OCR cache** from the Tools menu (after an update, or if an image is not re-read correctly).
- **Google Vision**: retries also cover bottom bands and side margins (bylines/credits) and merges useful OCR pieces; OCR cache bumped (v17).
- **Image OCR**: if the hit is only on the filename but OCR produced text, the result is `[IMG-OCR]` “Filename + OCR” and Copy OCR works.
- ZIP and last-minute arrivals 1.6.1, Vision OCR 1.6.0, practical guide/EPUB 1.5.9, local OCR 1.5.8, Mute 1.5.7 and complete mail 1.5.6 remain.
```

Asset(s):
