════════════════════════════════════════════════════════
COMUNE (Add-on + Standalone)
════════════════════════════════════════════════════════

- Descrivi immagine da URL, dagli Appunti o catturando lo schermo
  (gemello SA / Add-on); motore condiviso in rtad_ocr.
- Alt-text breve e Alt-text + descrizione lunga (menu contestuale).
- Descrivi immagine da PDF (Strumenti / menu sul risultato PDF).
- Elenco per tipo senza parola chiave (documenti/immagini/media):
  risultati [ELENCO]; per cercare DENTRO un PDF serve una parola.
- Restano Gemini/Vision/Explorer 1.6.3, notifica 1.6.2, ZIP 1.6.1.

════════════════════════════════════════════════════════
STANDALONE (in più)
════════════════════════════════════════════════════════

- Scorciatoie a finestra attiva: Ctrl+Shift+U (URL), Ctrl+Shift+I
  (Appunti), Alt+Shift+K (cattura e descrivi).
- CLI: --describe-url / --alt / --describe-pdf (oltre ai flag 1.6.3).
- Nessuna hotkey globale di sistema (evita conflitti con NVDA).

════════════════════════════════════════════════════════
ADD-ON (in più)
════════════════════════════════════════════════════════

- NVDA+Shift+G: figura sotto il navigatore (web, lettera g) oppure
  file immagine selezionato in Esplora file/Desktop.
- Fix: non riusa più un file ancora selezionato in Explorer in
  secondo piano mentre si descrive una figura web.

- Gemini/Vision 1.6.3, notification 1.6.2, ZIP 1.6.1 remain.
