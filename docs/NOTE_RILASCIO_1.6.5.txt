Descrizione:

```markdown
## 🇮🇹 Italiano

- Fix icone/grafici web (es. 3BMeteo): `NVDA+Shift+G` su SVG/WebP non apre più il dialogo wx «formato immagine sconosciuto»; fallback cattura area.
- Standalone Explorer: sottomenù **PDF** / **documenti** (Apri con app predefinita + voce in lista; Leggi testo; Copia testo; sui PDF anche Descrivi immagini).
- Restano Shift+G, URL/Appunti/cattura, `[ELENCO]`, Gemini/Vision 1.6.3, notifica 1.6.2.

## 🇬🇧 English

- Web icons/charts fix (e.g. 3BMeteo): `NVDA+Shift+G` on SVG/WebP no longer shows the wx «unknown image format» dialog; screen-area capture fallback.
- Standalone Explorer: **PDF** / **documents** submenu (Open with default app + list entry; Read text; Copy text; Describe images on PDF).
- Shift+G, URL/Clipboard/capture, `[ELENCO]`, Gemini/Vision 1.6.3, notification 1.6.2 remain.
```
