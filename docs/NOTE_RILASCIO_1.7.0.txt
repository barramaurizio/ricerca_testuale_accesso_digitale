Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.7.0

Descrizione:

```markdown
## 🇮🇹 Italiano

- **Lettore documento RTAD**: «Leggi documento…» con sommario, link e testo. Ctrl+F / F3 / Shift+F3 cerca nel corpo; Ctrl+H / Ctrl+Shift+H salta i titoli; «Apri file esterno» opzionale. Dopo iconizza, se le frecce non rispondono: Tab poi Shift+Tab.
- **Spazi PDF**: placeholder tipici (manuali Acer, braille, ecc.) → testo più leggibile. I PDF criptati restano fuori portata (serve copia senza protezione).
- **Toast fine-ricerca** meno invasivo (banner breve; resta nel Centro notifiche). Con il lettore aperto: solo annuncio.
- Restano PDF TOC/link 1.6.9, documenti 1.6.8, hub audio/video 1.6.7, dialogo immagine 1.6.6.

## 🇬🇧 English

- **In-app document reader**: “Read document…” with outline, links and body. Ctrl+F / F3 / Shift+F3 find in text; Ctrl+H / Ctrl+Shift+H jump headings; optional “Open external file”. After minimize, if arrows do nothing: Tab then Shift+Tab.
- **PDF spacing**: common space placeholders (Acer, braille manuals, …) become readable text. Encrypted PDFs stay out of reach (need an unlocked copy).
- **End-of-search toast** less intrusive (short banner; still in Notification Center). With the reader open: speech only.
- PDF TOC/links 1.6.9, structured docs 1.6.8, AV hub 1.6.7, and image dialog 1.6.6 remain.
```

Asset(s):
ricerca_testuale_accesso_digitale-1.7.0.nvda-addon
