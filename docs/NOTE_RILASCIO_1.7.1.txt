Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.7.1

Descrizione:

```markdown
## 🇮🇹 Italiano

- **PDF scansione**: se «Leggi documento…» non trova testo ma trova immagini, dialogo per descrivere subito l’immagine principale oppure aprire comunque il lettore.
- **Descrivi immagine da PDF**: «Salva testo…» usa nome e cartella del PDF originale (non del temp); nuovo «Stampa testo…» (stampante Windows / Print to PDF).
- **Scheda tecnica** (immagini e audio/video): **Data analisi** + **Ultima modifica originale** (come in Esplora file).
- **Lettore documento**: focus frecce dopo iconizza migliorato.
- Restano lettore/spazi/toast 1.7.0, TOC PDF 1.6.9, hub media 1.6.7.

## 🇬🇧 English

- **Scanned PDFs**: if “Read document…” finds no text but finds images, a dialog offers Describe now or open the reader anyway.
- **Describe image from PDF**: “Save text…” uses the original PDF name and folder (not the temp file); new “Print text…” (Windows printer / Print to PDF).
- **Tech sheet** (images and audio/video): **Analysis date** + **Original last modified** (as in File Explorer).
- **Document reader**: arrow-key focus after minimize improved.
- Reader/spacing/toast 1.7.0, PDF TOC 1.6.9, and AV hub 1.6.7 remain.
```

Asset(s):
ricerca_testuale_accesso_digitale-1.7.1.nvda-addon
