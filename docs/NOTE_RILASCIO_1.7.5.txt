- Guide: AV word search via `.rtad.txt`; Paste documented.
- Updater/shell/Browse 1.7.4 and earlier features remain.

## 🇮🇹 Italiano

- Tools → Find other copies on this PC: list, Desktop report, safe removal of Setup/Portable left in Downloads/Desktop (consent); startup tip when needed.
- Paste path from clipboard (Ctrl+Alt+V / Paste…) + drag-and-drop onto the window.
- HTML guide: AV via `.rtad.txt`, copies section, Paste.
