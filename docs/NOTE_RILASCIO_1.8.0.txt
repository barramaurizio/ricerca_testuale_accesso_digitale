Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.8.0

Descrizione:

```markdown
## 🇮🇹 Italiano

- Conversazione con Gemini sul file già aperto: immagine, documento e audio/video sul report. Più domande, data di oggi, cronologia sul PC, copia, salva e stampa.
- Pulsante «Conversazioni Gemini» e Strumenti (Ctrl+Shift+G); «Chiedi a Gemini» (Alt+G); dal menu di un risultato, Chiedi o Riprendi. Stesso sull’Add-on. Le cronologie dei due programmi restano separate.
- Web acceso: «Nel file» e «Approfondimento». Per un link: Tab fino a Apri fonte, poi Invio. Alt+F fa lo stesso, anche sull’elenco. Invio sull’elenco non apre il browser.
- La domanda va a capo; Invio invia. Da un URL la chat resta col titolo del video, non col file temporaneo.

## 🇬🇧 English

- Gemini conversation on a file already open: image, document, and audio/video from the report on screen. Follow-up questions, today’s date, history on this PC, copy, save and print.
- “Gemini conversations” button and Tools (Ctrl+Shift+G); “Ask Gemini” (Alt+G); from a result’s menu, Ask or Resume. Same in the add-on. The two programs keep separate histories.
- Web on: “In the file” and “Further reading”. To open a link: Tab to Open source, then Enter. Alt+F does the same even on the list. Enter on the list does not open the browser.
- The question wraps; Enter sends. From a URL the chat keeps the video title, not the temporary file name.
```

Asset(s):
