Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.8.1

Descrizione:

```markdown
## 🇮🇹 Italiano

- Correzione: se Gemini non manda un testo, la domanda e il motivo restano scritti nel riquadro Conversazione, anche senza voce. La stessa frase finisce nel log.
- Nella Standalone installata, in Esplora file, dentro «Cerca con Accesso Digitale», c’è «Chiedi a Gemini» sul file scelto. La domanda la scrivi tu.
- L’Add-on non aggiunge voci in Esplora file. Resta la conversazione sul file della 1.8.0.

## 🇬🇧 English

- Fix: if Gemini returns no text, the question and the reason stay written in the Conversation box, even with speech off. The same sentence is written to the log.
- In the installed Standalone, File Explorer’s “Search with Accesso Digitale” menu has “Ask Gemini” on the selected file. You still type the question.
- The add-on does not add File Explorer items. The 1.8.0 conversation on an open file remains.
```
