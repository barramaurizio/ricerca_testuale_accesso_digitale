Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.8.2

Descrizione:

```markdown
## 🇮🇹 Italiano

- Se Gemini è occupato sul primo modello (HTTP 503), RTAD prova il modello successivo. Vale per la chat, la descrizione immagine e l’audio/video.
- La frase a schermo non parla più di credito finito: o il servizio è occupato, o c’è un limite temporaneo di richieste. Se Google scrive che manca il pagamento, si legge quella frase.
- Una lettera, una azione. Sulla finestra principale: Alt+L chiave Google, Alt+H chiave Gemini, Alt+B conversazioni. Alt+G resta i Segnalibri. «Chiedi a Gemini» sul report resta Alt+G. Ctrl+Shift+G resta.
- Le cronologie di Standalone e Add-on restano separate.

## 🇬🇧 English

- If Gemini is busy on the first model (HTTP 503), RTAD tries the next model. This covers chat, image description, and audio/video.
- The on-screen sentence no longer talks as if the credit were gone: either the service is busy, or there is a temporary request limit. If Google writes that payment is missing, that sentence is shown.
- One letter, one action. On the main window: Alt+L Google key, Alt+H Gemini key, Alt+B conversations. Alt+G remains Bookmarks. “Ask Gemini” on a report remains Alt+G. Ctrl+Shift+G remains.
- Standalone and add-on histories stay separate.
```
