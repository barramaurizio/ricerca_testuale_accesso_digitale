Titolo:
Ricerca Testuale Accesso Digitale - NVDA Add-on v1.8.4

Descrizione:

```markdown
## 🇮🇹 Italiano

- Chiedi a Gemini da un resoconto già salvato (.rtad.txt), senza rifare l’analisi.
- Se accanto c’è ancora la foto, il video o il documento con lo stesso nome, quello resta il file di partenza. Gemini usa il testo già scritto.
- Se quel file non c’è più, la chat resta sul testo salvato e lo dice, a voce e a schermo: «Il file originale non è più accanto a questo resoconto. La conversazione resta sul testo salvato.»
- Un elenco ancora vuoto ha una frase vera, a schermo e in voce: «Nessuna ricerca avviata.», «Nessun risultato con questo filtro.», «Ancora nessuna fonte.», «Nessuna correzione nel glossario.»
- Nell’Add-on NVDA dice anche il percorso impostato, il testo salvato e i risultati esportati.
- Alt+A, il tetto di 12 e Shift+Invio restano. Standalone e Add-on insieme. Le cronologie restano separate.

## 🇬🇧 English

- Ask Gemini from a saved report (.rtad.txt), without running the analysis again.
- If the photo, video or document with the same name is still beside it, that file stays the starting file. Gemini uses the text already written.
- If that file is gone, the chat stays on the saved text and says so, on screen and by voice.
- An empty list has a real sentence, on screen and by voice: before a search, when a filter has no hits, when there is no source yet, and when the glossary has no rules.
- In the add-on, NVDA also speaks the path just set, the text just saved, and the exported results.
- Alt+A, the limit of 12 and Shift+Enter remain. Standalone and add-on together. Histories stay separate.
```

Asset(s):
