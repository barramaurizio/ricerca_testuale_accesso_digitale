## 🇮🇹 Italiano

- Whisper sul mio PC: casella spenta, accanto alla trascrizione. Al primo uso scarica il modello e trascrive anche senza chiave Gemini.

## 🇬🇧 English

- Whisper on this PC: the box is off, next to transcription. The first time, the model is downloaded. It works without a Gemini key.
- One file up to 20 minutes. In a folder, up to 5 files.
- The text becomes name.rtad.txt when that file is not already there. If it is, it stays as it was.
- Last tested NVDA version: 2026.3.
