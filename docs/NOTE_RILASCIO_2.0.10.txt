Descrizione:

```markdown
## 🇮🇹 Italiano

- In PDF e testo, Invio sul pulsante Scrivi il PDF, o un clic, scrive le pagine da-a del PDF selezionato. Pagina 1 è la prima del file. Se scrivi solo A, parte dalla prima. Se scrivi solo Da, arriva fino all'ultima. Il file si chiama nome-pagine-3-8. Con almeno due PDF, Invio sul pulsante Unisci i PDF, o un clic, li mette nell'ordine dell'elenco: il file si chiama nome1-pagine-1-13-unione-nome2-pagine-1-8-9-20. Da tre file in su: i primi due, con le loro pagine, e e-N. Se su una riga tieni più intervalli, restano tutti: Invio sul pulsante Tieni queste pagine, o un clic, aggiunge il blocco e non cancella i precedenti. Unisci i PDF e Unisci i testi usano tutti gli intervalli della riga, nell'ordine in cui li hai tenuti. Nell'elenco PDF, nell'ordine, il nome resta quello del file caricato, intero. Dopo Scrivi o Unisci, le pagine tenute si staccano da quella riga. Il nome nuovo sta solo in Fatti. Invio o doppio clic su un fatto lo rimette nell'elenco, se vuoi unire quel file nuovo. Invio sul pulsante Metti da parte, o un clic, toglie la riga dall'elenco di lavoro e la lascia in Da parte. Il file sul disco resta. Invio o doppio clic su una riga di Da parte la rimette nell'elenco. Un clic solo seleziona la riga. Invio sul pulsante Unisci i testi, o un clic, scrive un testo: ogni file è un titolo, sotto ci sono le pagine tenute, per esempio pagine 9-20 di 115. Lo Stato dice le stesse pagine. Vale anche con un solo PDF. Se la pagina non c'è: «La pagina 40 non c'è: questo file ne ha 12.» Un PDF di sole scansioni resta un PDF di quelle pagine. Il testo si crea lo stesso, e dentro c'è solo: «Nessun testo in queste pagine.» Se il PDF di partenza ha una firma, lo Stato dice che il file nuovo non la porta. Il file di partenza resta com'è. Se il nome c'è già, si aggiunge -2. Lo Stato, la barra di stato e Fatti dicono la stessa frase. Nella finestra, Control+Alt+V, oppure Invio sul pulsante Incolla, o un clic, mette il file o la cartella copiati. Le cartelle dentro non si aprono. Sul risultato PDF, nel menu: PDF e testo…. Invio sulla voce, o un clic. Vale nella Standalone e nell'Add-on. Nella Standalone installata, in Esplora file, tasto destro o tasto Applicazioni, Cerca con Accesso Digitale, su un PDF c'è PDF e testo. Invia a ha PDF e testo RTAD. Portable e Add-on: niente Invia a automatico.
- Nel lettore, Invio sul pulsante Salva la selezione, o un clic, scrive solo il testo selezionato: nome-selezione. Nel riquadro, Shift e le frecce, oppure NVDA+F9 e poi NVDA+F10 una volta sola. Se non c'è una selezione: «Nessun testo selezionato. Nel riquadro, Shift e le frecce, oppure NVDA+F9 e poi NVDA+F10 una volta sola. Poi Invio sul pulsante Salva la selezione, o un clic.» Salva testo resta tutto il documento. Vale per ogni documento aperto con Leggi documento, nella Standalone e nell'Add-on.
- Nel lettore, Invio o doppio clic su una sezione del sommario resta qui: va al testo di quella sezione. Non apre l'app predefinita. A schermo e a voce dice la sezione e, se c'è, la pagina di questo file. La figura della pagina si apre qui: scrivi il numero, oppure seleziona una sezione che indica la pagina, poi Invio sul pulsante Figura di questa pagina, o un clic. La pagina si vede nella finestra e il testo disegnato è nel riquadro sotto. Invio sul pulsante Tutto sull'immagine, o un clic, la descrive. Salva testo e Salva immagine scrivono accanto a questo PDF, con il nome del PDF e il numero di pagina: Invio sul pulsante, o un clic. Stampa testo e Stampa immagine mandano alla stampante: Invio sul pulsante, o un clic. Vale per ogni PDF aperto con Leggi documento, nella Standalone e nell'Add-on.
- Nell'Add-on, ultima versione NVDA testata: 2026.3.1. Le chat stanno nella cartella comune, insieme alla Standalone.

## 🇬🇧 English

- In PDF and text, Enter on Write the PDF, or a click, writes the page range of the selected PDF. Page 1 is the first page of the file. If you type only To, it starts at the first. If you type only From, it runs to the last. The file is named name-pagine-3-8. With at least two PDFs, Enter on Join the PDFs, or a click, puts them in list order: the file is named name1-pagine-1-13-unione-name2-pagine-1-8-9-20. From three files up: the first two, with their pages, and e-N. Each time you keep a range on a row, it stays. Join the PDFs and Join the texts use every range on that row, in the order you kept them. In the work list the name stays the file you loaded, the whole file. After Write or Join, the kept pages leave that row. The new name is only in Done. Enter or a double-click on a done item puts that new file back in the list, if you want to join it. Enter on Set aside, or a click, takes the row out of the work list and leaves it in Set aside. The file on disk stays. Enter or a double-click on a Set aside row puts it back in the work list. A single click only selects the row. Enter on Join the texts, or a click, writes one text: each file name is a heading, and under it the kept pages, for example pages 9-20 of 115. Status says the same pages. It also works with one PDF. If the page is not there: «La pagina 40 non c'è: questo file ne ha 12.» A scan-only PDF stays a PDF of those pages. The text file is still created, and inside it there is only: «Nessun testo in queste pagine.» If the original PDF is signed, Status says the new file does not carry the signature. The original file stays as it is. If the name exists, -2 is added. Status, the status bar and Done say the same sentence. In that window, Control+Alt+V, or Enter on Paste, or a click, puts in the copied file or folder. Folders inside are not opened. On a PDF result, the menu has PDF e testo…. Enter on the item, or a click. It works in the Standalone and in the Add-on. In the installed Standalone, in File Explorer, right-click or the Applications key, Search with Accesso Digitale, on a PDF there is PDF e testo. Send to has PDF e testo RTAD. Portable and Add-on: no automatic Send to.
- In the reader, Enter on Salva la selezione, or a click, writes only the selected text: name-selezione. In the text box, Shift and the arrows, or NVDA+F9 then NVDA+F10 once. If nothing is selected: «Nessun testo selezionato. Nel riquadro, Shift e le frecce, oppure NVDA+F9 e poi NVDA+F10 una volta sola. Poi Invio sul pulsante Salva la selezione, o un clic.» Save text still writes the whole document. It works for every document opened with Leggi documento, in the Standalone and in the Add-on.
- In the reader, Enter or a double-click on an outline section stays here and goes to that section's text. It does not open the default app. The same sentence on screen and by voice names the section and, when known, the page in this file. The page figure opens here: type the page number, or select a section that names the page, then Enter on Figura di questa pagina, or a click. The page is on screen and the drawn text is in the box below. Enter on Tutto sull'immagine, or a click, describes it. Enter on Salva testo, or a click, and Enter on Salva immagine, or a click, write beside this PDF, with the PDF name and the page number. Enter on Stampa testo, or a click, and Enter on Stampa immagine, or a click, send them to the printer. It works for every PDF opened with Leggi documento, in the Standalone and in the Add-on.
- Last NVDA version tested: 2026.3.1. The chats live in the shared folder, together with the Standalone.
```
