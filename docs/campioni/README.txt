Campioni per prove RTAD
=======================

prova_rtad_epub.epub
  Libro minimo per testare la ricerca EPUB (v1.5.9).

Come provare
------------
1. In Standalone o Add-on, percorso = questa cartella (docs\campioni)
   oppure copia il file dove preferisci.
2. Testo da cercare: MelagranoDigital
3. Tipo file: Tutti, oppure Solo Documenti, oppure estensione .epub
4. Avvia: deve comparire un risultato [EPUB] con snippet sul capitolo 1.

Parole alternative: accessibilità, biblioteca, Benvenuto.
